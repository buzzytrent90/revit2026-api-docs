#### Parameters

view [View](fb92a4e7-f3a7-ef14-e631-342179b18de9.md)

arc [Arc](1f5f541e-9335-aef3-0e75-59eed9ae2221.md)
     The extension arc of the dimension. 
firstRef [Reference](d28155ae-817b-1f31-9c3f-c9c6a28acc0d.md)
     The first geometric reference to which the dimension is to be bound. The reference must be perpendicular to the extension arc. 
secondRef [Reference](d28155ae-817b-1f31-9c3f-c9c6a28acc0d.md)
     The second geometric reference to which the dimension is to be bound. The reference must be perpendicular to the extension arc.

[Dimension](210f88be-e3c5-26a4-7dd8-3296f6725cce.md)If creation was successful the new angular dimension is returned, otherwise an exception with failure information will be thrown.
