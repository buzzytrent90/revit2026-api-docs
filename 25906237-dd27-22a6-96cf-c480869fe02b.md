#### Parameters

sizeInFloats Int32
     The size of the part of the buffer to be mapped, measured in floats. Must be less than or equal to the size of the [VertexBuffer](329e5617-ce46-a993-1131-85c64f0842f2.md)

| Exception | Condition |
| --- | --- |
| [InvalidOperationException](9e715f03-3884-e539-4dd6-8d7545733adc.md) | This VertexBuffer is not available because Revit is not currently rendering.
