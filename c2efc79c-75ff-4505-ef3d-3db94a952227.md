#### Parameters

view [View](fb92a4e7-f3a7-ef14-e631-342179b18de9.md)

     The point which the spot coordinate evaluate.

     The end point for the spot coordinate. 
refPt [XYZ](c2fd995c-95c0-58fb-f5de-f3246cbc5600.md)

hasLeader Boolean
     Indicate if it has leader or not.
