#### Parameters

reference [Reference](d28155ae-817b-1f31-9c3f-c9c6a28acc0d.md)
    A candidate reference in selection operation.
position [XYZ](c2fd995c-95c0-58fb-f5de-f3246cbc5600.md)
    The 3D position of the mouse on the candidate reference.

#### Return Value

BooleanReturn true to allow the user to select this candidate reference. Return false to prevent selection of this candidate.

If an exception is thrown from this method, the element will not be permitted to be selected.
