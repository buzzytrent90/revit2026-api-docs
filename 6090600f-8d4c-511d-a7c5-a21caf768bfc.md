#### Return Value

Boolean True if the ImageType can be reloaded. False, otherwise. 

The test first determines the candidate path for reloading the ImageType. Then the test checks that the corresponding file is a valid image file, that it is unencrypted, and that it contains the page corresponding to [PageNumber](2500b06c-f131-8d7b-3fb4-bd3e66335708.md).
