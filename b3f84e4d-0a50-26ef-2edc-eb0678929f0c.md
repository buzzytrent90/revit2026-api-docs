#### Parameters

barPositionIndex Int32
     An index between 0 and (NumberOfBarPositions-1). 

#### Return Value

[Transform](58dd01c8-b3fc-7142-e4f3-c524079a282d.md) The position of a bar in the set relative to the first position. 

| Exception | Condition |
| --- | --- |
| [ArgumentOutOfRangeException](60f148c9-ece0-a6bb-4e12-bb4a9c8c8a24.md) | barPositionIndex is not in the range [ 0, NumberOfBarPositions-1 ]. |
| [InvalidOperationException](9e715f03-3884-e539-4dd6-8d7545733adc.md) | This RebarShapeDrivenAccessor doesn't contain a valid rebar reference. |
  
The transform is a translation along the distribution path. It can be applied to the results of GetCenterlineCurves() to produce any bar in the rebar set. For barPositionIndex=0, the identity transform is always returned.
