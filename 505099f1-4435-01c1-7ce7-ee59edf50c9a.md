#### Parameters

phaseFilterType [LinkVisibility](f33e82f3-5bec-4532-457e-d01dc537024f.md)
     The type of the phase filter. 
phaseFilterId [ElementId](44f3f7b1-3229-3404-93c9-dc5e70337dd6.md)
     The id of the phase filter from the linked document or [InvalidElementId](08ae8886-6ab3-3ef5-d2e0-0da2ffa7bd2c.md). If phaseFilterType is set to [ByHostView](f33e82f3-5bec-4532-457e-d01dc537024f.md) or [ByLinkView](f33e82f3-5bec-4532-457e-d01dc537024f.md) the phaseFilterId must be set to [InvalidElementId](08ae8886-6ab3-3ef5-d2e0-0da2ffa7bd2c.md). If phaseFilterType is set to [Custom](f33e82f3-5bec-4532-457e-d01dc537024f.md) and phaseFilterId is [InvalidElementId](08ae8886-6ab3-3ef5-d2e0-0da2ffa7bd2c.md) the state of the phase filter will correspond to the None option in the UI.
