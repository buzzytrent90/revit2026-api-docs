#### Return Value

Boolean True if the schedule has at least one image field showing at least one image, false otherwise 

This method may return an incorrect value if the data of the schedule view is out of date. Check [!:IsDataOutOfData()], and call [RefreshData](db4ed392-dd6c-0354-575a-e3f9e315efcd.md) to ensure that the return value is correct.
