#### Return Value

[XYZ](c2fd995c-95c0-58fb-f5de-f3246cbc5600.md) A vector in model space representing the offset which is applied to the split crop region's boundary. 

| Exception | Condition |
| --- | --- |
| [ArgumentException](2e6e4206-97a8-dd4b-df5d-4269f4bb6088.md) | The provided region index is invalid. |
  
The points in the split crop region's boundary are not in model space. Add the offset returned by this method to each point in the crop region's boundary to transform the points into model space coordinates.
