# RevitLinkGraphicsSettingsLinkedViewId Property  
  
---  
  
The id of the linked view associated with this RevitLinkGraphicsSettings, or [InvalidElementId](08ae8886-6ab3-3ef5-d2e0-0da2ffa7bd2c.md) if no view is selected. If the [LinkVisibilityType](e48416ed-38f3-063d-cddd-8262486772b6.md) is set to [ByLinkView](f33e82f3-5bec-4532-457e-d01dc537024f.md), then there must be a valid LinkedViewId.
