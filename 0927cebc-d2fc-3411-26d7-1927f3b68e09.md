| Member name | Value | Description |
| --- | --- | --- |
| Contextual | 2 | The geometry object is visible in some contexts, but not in others. This type of geometry is always returned by [GeometryOptions](d8a55a5b-2a69-d5ab-3e1f-6cf1ee43c8ec.md), even when Revit is in a context where the geometry should not be visible, but only if [IncludeNonVisibleObjects](0d277b80-d5e5-1151-d413-b0899da0976f.md) is true. Examples of geometry of this class include Solids representing insulation and lining for MEP ducts and pipes. |
| Highlight | 1 | The geometry object is visible, but is affected by highlight or prehighlight special coloration. This type of geometry is returned by [GeometryOptions](d8a55a5b-2a69-d5ab-3e1f-6cf1ee43c8ec.md) if [IncludeNonVisibleObjects](0d277b80-d5e5-1151-d413-b0899da0976f.md) is true. |
| Invisible | 3 | The geometry object is never visible. This type of geometry is never returned by [GeometryOptions](d8a55a5b-2a69-d5ab-3e1f-6cf1ee43c8ec.md) but may be obtained by other API operations. |
| Visible | 0 | The geometry object is always visible. This type of geometry is always returned by [GeometryOptions](d8a55a5b-2a69-d5ab-3e1f-6cf1ee43c8ec.md) |
