#### Return Value

[RenderNodeAction](39f98799-628b-8d65-765c-ca86949ce7ed.md) Return RenderNodeAction.Proceed if you wish to receive low-level geometry (line segments) for this point, or otherwise return RenderNodeAction.Skip. 

Note that this method is invoked only if the custom exporter was set up to include geometric objects in the output stream. See [IncludeGeometricObjects](2ce1075e-380e-01e7-6459-b7467c2a2414.md) for mode details.
