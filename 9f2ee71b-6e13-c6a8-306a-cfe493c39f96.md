#### Parameters

document [Document](db03274b-a107-aa32-9034-f3e0df4bb1ec.md)
     The Document containing the Revisions. 
revisionId [ElementId](44f3f7b1-3229-3404-93c9-dc5e70337dd6.md)
     The Revision that should have its clouds and tags associated with the next Revision. 

#### Return Value

ISet[ElementId](44f3f7b1-3229-3404-93c9-dc5e70337dd6.md) The ids of all RevisionClouds that were reassigned to the next Revision. 

| Exception | Condition |
| --- | --- |
| [ArgumentException](2e6e4206-97a8-dd4b-df5d-4269f4bb6088.md) | revisionId is not a valid Revision. -or- This operation cannot be performed because revisionId is an issued Revision. -or- revisionId cannot be combined with the next Revision because either revisionId is the last Revision or the next Revision has already been issued. |
| [ArgumentNullException](631e1424-60f4-929b-4e52-dda9dcd26316.md) | A non-optional argument was null |
  
All RevisionClouds and tags associated with the specified Revision will be reassigned to the next Revision in the model and the specified Revision will be deleted from the model. The operation can only be performed if both the specified Revision and the next one are unissued.
