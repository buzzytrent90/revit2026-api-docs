| Exception | Condition |
| --- | --- |
| [InvalidOperationException](9e715f03-3884-e539-4dd6-8d7545733adc.md) | When setting this property: Display of footer rows is not enabled. |

ShowFooterTitle can only be enabled if ShowFooter is enabled.
