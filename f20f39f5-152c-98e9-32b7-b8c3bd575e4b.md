#### Return Value

[FieldBuilder](13cd8e7c-acc8-af6e-0ae6-a9b77fcd913c.md) The FieldBuilder object may be used to add more details to the field. Make sure to set the unit type if the field contains floating-point values. 

| Exception | Condition |
| --- | --- |
| [ArgumentException](2e6e4206-97a8-dd4b-df5d-4269f4bb6088.md) | The parameter fieldName is not acceptable for naming Extensible Storage objects. -or- The field type is not supported. |
| [ArgumentNullException](631e1424-60f4-929b-4e52-dda9dcd26316.md) | A non-optional argument was null |
| [InvalidOperationException](9e715f03-3884-e539-4dd6-8d7545733adc.md) | The SchemaBuilder has already finished building the Schema. |
  
The supported types for the contents are the same as for simple fields. See [AddSimpleField(String, Type)](5de0ea30-a58e-4db2-373c-05222a139465.md) for details. 

Note that a schema may contain a maximum of 256 fields.
