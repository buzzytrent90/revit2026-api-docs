# RevitLinkGraphicsSettingsColorFill Property  
  
---  
  
The color fill of RevitLinkGraphicsSettings. The color fill can be set to [ByHostView](f33e82f3-5bec-4532-457e-d01dc537024f.md) or [ByLinkView](f33e82f3-5bec-4532-457e-d01dc537024f.md). Only a view that supports color fill can have this property set to [ByLinkView](f33e82f3-5bec-4532-457e-d01dc537024f.md). To check if the view supports the color fill use [SupportedColorFillCategoryIds](84197491-81de-0713-06bf-fa7073419485.md) to see if there is any supported color fill category for the view. The [LinkedViewId](053b6a8c-2212-322c-8f21-b7d95e089b42.md) parameter must have a value assigned if this property is set to [ByLinkView](f33e82f3-5bec-4532-457e-d01dc537024f.md).
